# SEYVEO — Россия (seyveo.ru)

Независимый презентационный сайт российской аудитории SEYVEO в утверждённом стиле Black Velvet / White Velvet.

## Состав
- index.html — главная страница на русском языке.
- assets/style.css — адаптивные стили и обе темы.
- assets/site.js — переключение темы и меню.
- assets/official-logo.svg — фирменный знак студии.

**Текущий статус:** сайт создан в GitHub, но домен seyveo.ru ещё не подключён. До завершения согласования контента страница помечена noindex. Отдельный сайт seyveo.com предназначен для международной аудитории, включая русскоязычные страны СНГ.

## Публикация
После проверки страниц включить GitHub Pages для main / root, проверить временный URL и только потом подключить seyveo.ru через DNS, не затрагивая записи почты (MX / SPF / DKIM / DMARC). Убрать noindex лишь после утверждения сайта и запуска домена.

**Важно:** продукты LIFE / PRO / MAX находятся на стадиях разработки и концепции. Сайт не должен обещать готовые возможности или работающие подписки.

## Лозунги продуктов (решение владельца)

На главной презентационной странице компании **не размещать** лозунги продуктов общим блоком. Каждый отдельный продукт или самостоятельное продуктовое предложение получает собственный лозунг в своём контексте; не смешивать названия продуктов с уровнями LIFE / PRO / MAX и не придумывать неподтверждённые слоганы.

- **Business Start** (путь запуска бизнеса): «Один маленький шаг для вас. Гигантский скачок для вашего бизнеса.» — утверждённый продуктовый лозунг. Он не является общим слоганом SEYVEO, LIFE / PRO / MAX или всех бизнес-предложений.
- «SEYVEO. Рядом на каждом этапе жизни.» — ранее использованная общая брендовая фраза, но **не размещать автоматически** на главной рядом с продуктовыми лозунгами. Использование в будущем — только в подходящем контексте по решению владельца.
- Для остальных продуктов отдельные лозунги ещё не назначены; не заполнять их произвольно.
