# SEYVEO — Россия (seyveo.ru)

Независимый презентационный сайт российской аудитории SEYVEO в утверждённом стиле Black Velvet / White Velvet.

## Состав
- `index.html` — главная страница студии SEYVEO: выбор двух направлений без смешения аудиторий.
- `life/index.html` — самостоятельная продуктовая страница **SEYVEO ONE** («Жизнь»): лёгкий личный помощник; без бизнес-CRM.
- `business/index.html` — самостоятельная страница **SEYVEO BUSINESS / «Цифровой управляющий»**: создание бизнеса с нуля и развитие компании; уровни **RISE / AUTONOM**.
- `assets/style.css` — один адаптивный дизайн Black Velvet / White Velvet, поддержка iPhone.
- `assets/site.js` — переключение темы и мобильное меню.
- `assets/official-logo.svg` и файлы плазмы — существующий фирменный визуал.

**Согласованная архитектура (22.10.2026):** две отдельные продуктовые аудитории и две страницы сайта, **один бренд, одна Сэйви и общая технологическая основа**. Для начала не создавать две разные кодовые базы мобильного приложения. Первый запуск приложения уже разделяет «Жизнь» и «Бизнес»; выбор пользователя не заменяет выбор и оплату подписки. ONE не включает бизнес-функции. В BUSINESS уровня RISE достаточно для пути «начать с нуля» и «уже есть дело»; AUTONOM — расширенная работа по разрешённым правилам. Переход ONE → BUSINESS в будущем только добровольный, без потери личных данных — после разработки аккаунта/синхронизации и проверки миграции.
- assets/official-logo.svg — фирменный знак студии.

**Текущий статус:** сайт создан в GitHub, но домен seyveo.ru ещё не подключён. До завершения согласования контента страница помечена noindex. Отдельный сайт seyveo.com предназначен для международной аудитории, включая русскоязычные страны СНГ.

## Публикация
После проверки страниц включить GitHub Pages для main / root, проверить временный URL и только потом подключить seyveo.ru через DNS, не затрагивая записи почты (MX / SPF / DKIM / DMARC). Убрать noindex лишь после утверждения сайта и запуска домена.

**Важно:** продукты ONE / BUSINESS (RISE, AUTONOM) находятся на стадиях разработки и концепции. Сайт не должен обещать готовые возможности, подключения, партнёрства или работающие подписки.

## Сообщения и поисковая структура

- На главной странице студии нет общего рекламного обещания «игры + бухгалтерия»; она только показывает два чётких направления.
- `/life/` — отдельная будущая SEO-страница для личного помощника, знаний, общения, игр, здоровья и домашней помощи; никаких заявлений о лечении, слежении или поддерживаемой интеграции с PlayStation, Spotify или Алисой.
- `/business/` — отдельная будущая SEO-страница про создание и управление бизнесом, осмысленные действия, клиентов, процессы и разрешённые интеграции; RISE и AUTONOM — уровни, не два отдельных приложения.
- Для SEO нужна реальная функциональность, проверенные формулировки поискового спроса, уникальный полезный контент и работающий домен. Пока **везде `noindex,nofollow`**, `seyveo.ru` не подключён; не снимать ограничение раньше готовности сайта.
- Контактный адрес на страницах — подтверждённый `hello@seyveo.com`. Изменения DNS сайта не должны затрагивать почтовые записи домена.
- Старые названия LIFE / PRO / MAX, Business Start и старые лозунги — архив решений, не копировать их на рекламные страницы.

## Тематические входы из поиска (SEO) — прототип 22.10.2026

**Решение владельца:** человек ищет помощь для игры, здоровья, создания сайта или правил ведения бизнеса и попадает сразу на страницу SEYVEO по своей теме. Там сначала получает **полезный ответ**, а потом узнаёт о соответствующей будущей способности одной Сэйви.

**Реализованные предварительные страницы:**
- `/life/games/` — беседа и подсказки по играм: как задавать вопрос по кадру, избегать спойлеров, не обещать доступ к PlayStation.
- `/life/health/` — личная организация здоровья: вопросы врачу, записи и напоминания; без диагнозов и назначений.
- `/business/website/` — практический план создания сайта для малого бизнеса, без имитации работающего сайта-конструктора.
- Юридические вопросы — **пока не отдельная SEO-страница**: на `/business/` есть переход к официальному сервису ФНС. Для собственной тематической страницы нужны качественный проверенный материал и актуальные первоисточники.

**Технический принцип:** запрос пользователя из Яндекса/Google как правило недоступен сайту как отдельная фраза; точная тема определяется самой поисковой страницей и её URL, а не скрытой слежкой за пользователем. Пример диалога с Сэйви обозначен как **концепция**; настоящий ИИ, отправка фото, доступ к играм, Health и создание сайтов пока не подключены.

**SEO-политика:** избегать сотен одинаковых дорвейных страниц, не скрывать материалы от роботов и не показывать посетителям отличающийся «продающий» контент. Каждая страница должна самостоятельно решать информационную задачу. Пока везде `noindex,nofollow`; это осознанное ограничение прототипа. **До запуска поиска:** проверить юзабилити на iPhone, качественный контент, правовые/медицинские источники, фактическую работу рекламируемых способностей; подключить домен; проверить серверные ответы и индексацию, согласовать снятие `noindex`; настроить Яндекс Вебмастер/Google Search Console и аналитику только с соблюдением применимых правил. Индексация и место в выдаче не гарантируются.
